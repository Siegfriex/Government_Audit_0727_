# 텍스트 정리 규칙

원문을 덮어쓰지 않고 정리된 텍스트를 별도 열에 저장합니다.

| 순서 | 규칙 | 목적 |
|---:|---|---|
| 1 | Unicode NFKC | 모양이 같은 호환 문자를 같은 표현으로 통일 |
| 2 | NUL 제거 | 추출 과정의 제어 문자 제거 |
| 3 | 줄바꿈을 공백으로 변환 | 페이지 줄바꿈을 한 문장 흐름으로 연결 |
| 4 | 다중 공백을 한 칸으로 정리 | 불필요한 간격 제거 |
| 5 | 앞뒤 공백 제거 | 비교 가능한 문장 생성 |
| 6 | 문자 검색용 공백 제거 | char n-gram 검색 입력 생성 |

숫자·날짜·기관명·구두점은 의미가 달라질 수 있어 임의 치환하지 않습니다. 형태소 분석이나 stemming은 사용하지 않습니다.
