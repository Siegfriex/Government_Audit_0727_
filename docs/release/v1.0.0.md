## 프로젝트 요약

처리결과보고서의 문제·조치 문장과 국정감사 회의록의 질문·답변을 연결하고, 검토 완료 761개 분석 단위를 24개 주제 구역과 140개 Atlas 노드로 구성했습니다.

## 파이프라인

```text
PDF → Page → Block → Speaker Turn → Retrieval Segment
→ TF-IDF top 50 → MiniLM rerank → RRF → 검토 완료 데이터
→ char TF-IDF → SVD 96D → KMeans 24 → UMAP 2D
→ Atlas Node 140 → React ViewModel → Vercel
```

MiniLM은 TF-IDF 후보의 의미적 순서를 다시 정리하는 데만 사용하며 Atlas 좌표에는 사용하지 않습니다.
